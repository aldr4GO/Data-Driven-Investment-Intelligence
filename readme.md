# 📈 Strategic Stock Prediction: Nifty 50 & NSE Ensemble

Welcome to the **Strategic Stock Prediction** project! This repository contains a robust, intermediate-level machine learning ensemble designed to predict the 1-day forward direction of assets within the Nifty 50 and the broader National Stock Exchange (NSE) of India using **XGBoost** and **LightGBM**.

## 🛠 1. Environment Setup

To ensure complete reproducibility and avoid dependency conflicts, it is highly recommended to run this project inside an isolated virtual environment.

### Prerequisites:
* **Python**: `3.8`, `3.9`, or `3.10`
* **OS**: Linux, macOS, or Windows

### Create a Virtual Environment:
```bash
# Using venv (Built-in Python)
python -m venv stock_env

# Activate the virtual environment
# For Linux/macOS:
source stock_env/bin/activate
# For Windows:
stock_env\Scripts\activate

dependency installation:
```
pip install pandas numpy matplotlib seaborn tqdm scikit-learn xgboost lightgbm jupyter
```
